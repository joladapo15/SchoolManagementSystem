School Management System 

A simple School Management System built in Python that allows users to manage students, faculty, and courses.
This project demonstrates object-oriented programming (OOP), file handling with CSVs, and menu-driven user interaction.

Features

Add and view students, courses, and faculty

Enroll students in courses

Assign faculty to courses

Save data to CSV files for persistence

Simple interactive menu for navigation


SchoolManagementSystem/
│
├── SMS_student.py         # Student class
├── SMS_faculty.py         # Faculty class
├── SMS_course.py          # Course class
├── school.py          # Main school system logic
├── SMS_main.py        # Menu and program entry point
├── students.csv       # Stores student data
├── courses.csv        # Stores course data
├── faculty.csv        # Stores faculty data
└── README.md          # Project overview


How to Run

Clone the repository

git clone https://github.com/joladapo15/SchoolManagementSystem.git
cd SchoolManagementSystem


Run the main program

python SMS_main.py
